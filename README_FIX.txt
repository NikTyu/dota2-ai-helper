ОСНОВНАЯ ДОКУМЕНТАЦИЯ — README.md (архитектура агента, установка, запуск). Ниже — история изменений.

ИСПРАВЛЕНИЯ
- main.py формирует предметы из реально существующих карточек базы.
- Ollama qwen2.5:7b используется для ранжирования допустимых предметов, но НЕ генерирует их названия или свойства.
- Убрана подача 186 полных карточек в контекст LLM.
- Убрано принуждение заполнять по 5 штук в каждой категории.
- Неизвестные герои останавливают анализ вместо выдуманных матчапов.
- При недоступной Ollama работает резервное ранжирование по базе.

ЗАПУСК (PowerShell, терминал VS Code):
py -m pip install ollama
ollama pull qwen2.5:7b
py main.py

Если py не работает, попробуй python вместо py.
Запускай из папки проекта, где лежит main.py.
ОГРАНИЧЕНИЕ: файлы базы могут содержать ошибки и устаревшие данные.

ВЕБ-ИНТЕРФЕЙС:
py web.py
Откроется браузер на http://127.0.0.1:8000 (если нет — открой адрес вручную).
Слева выбираешь своего героя, союзников и врагов, справа — билд по категориям.
Клик по предмету открывает его полную карточку из базы. Отчёт так же сохраняется в build_<hero>.txt.
Порт можно сменить: переменная окружения DOTA_PORT. Консольный режим (py main.py) работает как раньше.

КАРТИНКИ ГЕРОЕВ И ПРЕДМЕТОВ:
Лежат в static/img/heroes и static/img/items (портреты с CDN Valve, имена сверены через OpenDota).
Если в базу добавлены новые герои/предметы — py download_images.py докачает недостающие.
Без картинки интерфейс показывает цветную плитку с инициалами.

СИТУАЦИИ В ИГРЕ (веб-интерфейс):
Под списком героев выбери, как идёт игра: отстаём, выигрываем, много магии, физ. урона, контроля,
невидимость, иллюзии, хил, уклонение, затяжная игра. Можно отметить несколько.
К билду добавится блок «4. По ситуации в игре» — только предметы из базы, с учётом позиции
(Авто / Кор 1–3 / Саппорт 4–5) и типа атаки героя. Красная точка на ситуации — подсказка по вражескому драфту.
Списки предметов и героев-подсказок — в situations.py.

ФИЛЬТР СОВМЕСТИМОСТИ ПРЕДМЕТОВ (compat.py):
Ситуативные предметы и предметы по ситуациям проверяются на совместимость с героем ДО ранжирования
(в том числе до Ollama). Профиль героя строится по его карточке: позиция, тип атаки, атрибут, основной закуп.
- предметы на урон с руки (Eye of Skadi, Butterfly, MKB...) — только героям, которые бьют с руки;
- предметы коров (Bloodthorn, Assault Cuirass...) — не саппортам; саппортские (Glimmer Cape, Mekansm...) — не керри;
- Heaven's Halberd, Crimson Guard, Blade Mail — силовикам и героям ближнего боя;
- Witch Blade / Parasma — корам с интеллектом; вторые базовые ботинки не предлагаются;
- стартовые расходники и голые компоненты не попадают в ситуативные.
Пример: Phoenix против Huskar больше не получает Eye of Skadi.
